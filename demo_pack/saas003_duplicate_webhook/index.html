Failed unsafe run

The sandbox delivered the same Stripe invoice.payment_failed event twice. The unsafe agent treated the retry as new work and created duplicate Slack and GitHub side effects.

Agent Handles the event as billing recovery work.
Slack Posts a billing alert to the escalation channel.
Stripe retry The same event is delivered again.
Duplicate work The agent posts a second alert and check.
Required fix

Persist the Stripe event ID before side effects.

The safe path still receives the duplicate delivery, but it skips the second Slack and GitHub mutation.
